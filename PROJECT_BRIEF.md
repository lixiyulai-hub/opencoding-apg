# OpenCoding Project Brief

品牌名：OpenCoding
仓库 slug：opencoding-apg
兼容别名：Adaptive Project Governance（adaptive-project-governance）、APG

## Problem and users
OpenCoding 面向不会写代码、刚开始使用 AI coding 的人。它把中文想法、需求澄清、平台与架构判断、项目文档、任务编排、agent 执行、测试、独立审核、恢复和交付串成一套可审计的 AI Coding 治理工作流。APG 是历史兼容标识，不是产品范围的限定词。

## Outcomes and scope
- Desired outcome: 让小白用户从一句话想法得到可理解、可执行、可检查、可恢复的 AI coding 项目交付路径。
- In scope: requirement clarification, project decisions, project-specific documents, dependency-aware task waves, agent/provider orchestration, verification, independent review, recovery, receipts, and human Gates。
- Out of scope: claiming universal agent compatibility, silently activating external services, production deployment, or public release without their own evidence and human Gate。

## Evidence tasks
- Confirm users, ownership, lifecycle, and release model。
- Replace unknown data and exposure classifications with evidence。
