Use the `opencoding` skill as the product-facing entry. Prefer the repository's `python -m opencoding` runtime when this repository is available; otherwise route to the host-local `adaptive-project-governance` controller. Audit first, preview before writes, require explicit authorization for `--apply`, and preserve receipts, rollback evidence, and human Gates.
