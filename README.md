# OpenCoding（APG）

## 中文介绍

OpenCoding 帮助不会写代码、刚开始学 AI coding 的人，把一个模糊想法整理成清楚、可执行、可验证的项目计划。

你可以用自然语言描述想法，OpenCoding 会帮助你：

- 通过 Grill Me 追问关键需求，减少遗漏和反复修改；
- 自动整理项目说明、知识包、任务清单和任务顺序；
- 把大目标拆成小步骤，明确每一步要做什么、如何检查；
- 先用离线流程演练，再生成验证结果、证据和回滚方案；
- 在涉及密钥、金钱、网络、部署或发布时停在人工确认点。

一句话：**让小白也能把一个想法，变成一套清楚、稳妥、能检查的 AI coding 项目计划。**

本仓库是 APG-only 治理与验证夹具，不实现儿童知行星球下游产品。

## English

OpenCoding helps people who do not know how to code yet, or are new to AI coding, turn a rough idea into a clear, executable, and verifiable project plan.

With a natural-language idea, OpenCoding can:

- ask focused questions through Grill Me to clarify requirements;
- organize project notes, knowledge packs, tasks, and task order;
- break a large goal into small steps with checks for each step;
- rehearse the workflow offline before producing evidence and rollback steps;
- stop for human confirmation before secrets, money, network, deployment, or release actions.

In one sentence: **OpenCoding helps beginners turn an idea into a clear, controlled, and checkable AI coding plan.**

This repository is an APG-only governance and validation fixture. It does not implement the downstream child product.
