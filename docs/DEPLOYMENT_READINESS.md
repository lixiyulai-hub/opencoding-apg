# Deployment Readiness（部署准备检查）

这个模块把“要不要真正让 APG 生效”前的技术问题，自动翻译成小白能看懂的结果。

## 三种结果

- `ready`：资料齐全，可以进入下一步确认；仍不会自动部署。
- `needs-owner-gate`：资料还缺一些，或者需要你确认一次；系统会列出缺什么。
- `blocked`：资料不安全、范围不清或不允许继续；系统会停止。

## 自动检查的五件事

1. **目标**：文件最终放到哪里。
2. **制品**：使用哪一份已经验证过的 APG 文件，以及校验值。
3. **上下文**：是否联网、用密钥、花钱、使用真实数据、改 Git、启动运行时。
4. **回滚**：出错后如何恢复原状。
5. **接受标准**：怎样判断“确实成功”。

## 当前项目的实际结论

当前 Codex Host 部署仍缺少一个新的具体生效授权，因此自动检查应返回
`needs-owner-gate`，而不是擅自部署。此前的本地测试、隔离安装和回滚证据只能证明
“准备流程可行”，不能代替你对真实生效动作的确认。

## 边界

评估器只读取和重算声明，不执行部署、不重载 Host、不访问网络、不改 Git，也不推进
publication、pilot 或 release。
