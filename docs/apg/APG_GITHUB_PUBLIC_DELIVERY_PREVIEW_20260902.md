# OpenCoding / APG GitHub 公共交付 Preview（2026-09-02）

## 首屏定位

**把一句想法，变成一套能自动推进的项目计划。**

APG 面向普通小白和 AI coding 初学者。用户用中文描述想法，Grill Me 解释式追问，APG 自动生成项目 Markdown 知识包、需求拆分、任务图、验证证据和回滚方案。

## 自动化原则

普通路径自动执行安全默认值，不要求用户理解技术术语或反复审批。只有密钥、金钱、网络、部署目标、真实数据、Git/公开发布和不可逆外部动作才触发一次 consequential Gate。
