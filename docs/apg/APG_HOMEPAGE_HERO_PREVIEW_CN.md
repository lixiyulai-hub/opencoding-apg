## 第一眼必须看懂的三件事

- **这是做什么的？** 把自然语言想法变成项目专属 Markdown 知识包、任务图和可验证的执行计划。
- **我需要懂技术吗？** 不需要。系统会解释为什么提问，并自动采用安全默认方案。
- **下一步是什么？** 说一句中文想法，进入 Grill Me；随后 APG 自动整理并报告结果。

## 自动循环

`INSPECT → PROGRESS → PLAN → DISPATCH → VALIDATE → REPORT → REQUEUE`

普通工作自动推进。只有密钥、金钱、网络、部署目标、真实数据、Git/公开发布或不可逆外部动作，才合并为一次 consequential Gate。
