# OpenCoding / APG 下一阶段目标：初心者交互体验与执行器连接

正式品牌：OpenCoding；APG 保留为兼容技术标识。

确认日期：2026-09-01

## 目标结论

APG 下一阶段正式目标是：让普通小白或 AI coding 新手能够用中文自然语言开始一个项目，并在 APG 的引导下完成需求澄清、项目文档生成、需求拆分、任务编排、验证与交付；同时定义并逐步接入受控的 AI coding 执行器。

## 目标组成

1. **初心者交互层**：中文优先入口、Grill Me 追问、术语解释、下一步提示和可恢复会话。
2. **项目知识包**：按项目类型生成 `PROJECT_BRIEF`、`PRODUCT_PLAN`、`UX_FLOW`、`ARCHITECTURE`、`STACK_DECISION`、`TASK_GRAPH`、`QUALITY_PLAN`、`DEPLOYMENT_PLAN`，并按需生成 PRG plan、memory、agents、design 等 Markdown 文档。
3. **需求与执行编排**：把自然语言目标拆为需求、依赖、任务波次、Gate、证据、验收和回滚。
4. **执行器适配器契约**：定义任务上下文、读写范围、Gate 前置条件、输出回传、错误分类、重试和回滚接口。
5. **分阶段落地**：离线模拟器 → 契约测试 → 受控本地执行 → 独立复核。

## 明确边界

本目标只确认产品方向与下一阶段治理计划，不代表已经连接 Codex、Claude Code、Cursor 或其他 Host，也不授权 Provider、网络、凭据、真实数据、运行时、Git、部署、发布或下游产品执行。每一个外部或不可逆边界都必须创建新的精确 plan-change、Gate、证据和回滚。

## 验收标准

- 新手可以用一句中文想法进入 Grill Me 流程；
- 系统能说明还缺什么信息以及为什么要问；
- 系统能输出项目专属 Markdown 知识包和任务图；
- 系统能把任务分为可自动推进、建议选择和必须确认；
- 执行器连接先以离线契约和模拟结果证明，不以“已安装”或“已发布”替代；
- 失败、阻断、回滚和独立复核均有可重放证据。
