# APG 初心者任务波次

任务不是一股脑丢给小白，而是按依赖分波次安排：

1. **想法和需求**：intake、Grill Me、项目目标；
2. **平台和方案**：平台建议、前后端方案、方案确认；
3. **产品和界面**：产品计划、用户流程、系统架构；
4. **基础能力**：服务器、数据库、API、登录、文件存储（按需）；
5. **业务集成**：支付、消息通知、后台管理（按需）；
6. **测试和验收**：质量计划、离线验证、证据；
7. **报告和下一步**：报告、Requeue、下一轮计划。

每波都有依赖和可重放顺序。普通离线任务自动推进；真实网络、费用、密钥、部署、生产数据、远程 GitHub 或不可逆动作合并为一次人工 Gate。失败时冻结当前波次，修正输入后从最近有效节点 Requeue。
